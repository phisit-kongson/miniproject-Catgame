# miniproject-Catgame
เปิดมาเป็นหน้าเกมก่อนเข้าเกมมีปุ่ม play กดเข้าไปในตัวเกม
เปิดมาจะมีเเมวอยู่หน้าหลักและเป็นห้องหลักมีระบบเงินเป็น coin ด้านซ้ายมือ และมี icon ต่างๆด้านล่าง 4 อัน ดังนี้
shop ---> เปิดขึ้นมาเป็นหน้าร้านค้าขายของอาหารเเมวต่างๆ กดเลือกสินค้าและบอกจำนวนเเล้วกดยืนยันเป็นการซื้อเสร็จสิ้น
feed ---> ย้ายไปอีกห้องนึงเป็นห้องครัวมีเเถบบอกค่าสถานะความหิว(hungry) แล้วมีเมนูสินค้าขึ้นด้านล่างข้างจอกดเลือกเเละให้อาหารเเมว เป็นการเพิ่มค่าสถานะ
sleep ---> ย้ายไปอีกห้องนึงเป็นห้องนอนมีเเถบบอกค่าสถานะความง่วง เมื่อกดไปที่ตัวเเมว แมวจะนอนเเล้วค่าสถานะจะเพิ่มขึ้น
toilet ---> ย้ายไปอีกห้องนึงเป็นห้องน้ำมีเเถบค่าสถานะความสะอาด เมื่อกดที่ตัวเเมวแมวจะเข้าห้องน้ำและค่าสถานะจะเพิ่มขึ้น
ระบบ coin จะมีตั้งต้นที่ 10 เหรียญ สามารถนำไปใช้ซื้อสินค้าในช็อปละ coin จะลดลง สามารถได้ coin เพิ่มขึ้นจากการทำกิจกรรม ให้อาหาร นอน เข้าห้องน้ำ

## Cat Game

เป็นเกมจำลองการเลี้ยงแมว 

* 1.Lobby หน้าเข้าเกม มีปุ่มกดเข้าเกม มีระบบSign up และ login

* 2.GameFrame หน้าเกมเล่นกับแมว และมีฟังชั่น
  
-shop หน้าเลือกซื้ออาหาร จะบอกชื่อสิ้นค้า และราคา

-Feed ปุ่มกดให้อาหารแมว

-Sleep ห้องนอนของแมว

-Toilet ห้องน้ำแมว ห้องอาบน้ำให้แมว

-Coin แทบบาร์แสดงจำนวนเงิน

-Quest ภารกิจที่ต้องทำเผื่อรับ Coin

* 3.Cat ตัวแมวในเกม
  
-แสดงแถบค่าความหิว

-แสดงแถบพลังงาน

-บอกความสะอาดของแมว

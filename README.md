Mini Project: Cat Game
เป็นเกมจำลองการเลี้ยงแมว
1.Lobby หน้าเข้าเกม มีปุ่มกดเข้าเกม
2.GameFrame หน้าเกมเล่นกับแมว และมีฟังชั่นต่างๆ
-shop หน้าเลือกซื้ออาหาร จะบอกชื่อสิ้นค้า และราคา
-Feed ปุ่มกดให้อาหารแมว
-Sleep 
-Toilet 
-Coin แทบบาร์แสดงจำนวนเงิน
3.Cat ตัวแมวในเกม
-แสดงแถบค่าความหิว
-แสดงแถบพลังงาน
-บอกความสะอาดของแมว
